# Portfolio live demos

Interactive front ends you can use in the browser (no backend).

## Enable GitHub Pages (one time)

1. Open https://github.com/Invenitur42/portfolio-live-demos/settings/pages  
2. **Source:** Deploy from a branch  
3. Branch: **main** / **/ (root)** → Save  

After a minute the site is at:

**https://invenitur42.github.io/portfolio-live-demos/**

| Tool | Link |
|------|------|
| Home | https://invenitur42.github.io/portfolio-live-demos/ |
| Project Manager | https://invenitur42.github.io/portfolio-live-demos/pm/ |
| Finance | https://invenitur42.github.io/portfolio-live-demos/finance/ |
| Doc Chat | https://invenitur42.github.io/portfolio-live-demos/rag/ |

Until Pages is enabled, open the HTML files from this repo locally or use `npx serve .`.
